## How the list was built

- **Deduplicated** within each locality: discovery entries answering the same question share one process id (for example new and renewal business licences, or assessor review and Board of Equalization appeal).
- **Aligned** across localities: the same process has the same id everywhere, so one state-law model can serve all three places.
- **Priority.** High: needed often by many residents or businesses and governed by rules or deadlines with legal consequences. Medium: regular but narrower, or frequent but low-stakes. Low: rare, or a booking, sign-up, lookup or program with little procedure.
- **Selected** (up to 20 per locality): every high process, then medium ones in one shared order of importance, preferring a clear legal basis and an official procedure page. Charlottesville's FOIA and business licence processes are already answered in `curated/places/va/charlottesville.json`, so they are listed but not selected.
- **Sources** are official pages from the discovery files and the state backbone. State-backbone-only processes (no locality page recorded) cite the court page on vacourts.gov.

## The researched process files

The 20 selected processes of each locality were researched into one file each, `curated/places/va/<place>/<process>.json` (60 files), drafted with an AI system and passed by an AI verifier. `run local` loads them into `place_processes`. A file gets a wiki page only when it counts as verified (below).

**lexflow's quote check.** lexflow's software matches every quote in a file (`places.check_quotes`, `lexflow/municipal/quotes.py`), with the state models' matcher (`validate.quote_in`) after spacing, curly quotation marks, odd spaces, soft hyphens and ligatures are normalised:

- a quote that cites a Code of Virginia section is matched to Open US Law's copy of that section;
- any other quote is matched to the page or PDF it cites, and failing that to another page the file cites. PDFs are read with pdftotext (reading order, raw, layout and table passes), also with line-end hyphens joined and page numbers at page breaks dropped. A Word redline (an ordinance on Legistar) is read as it stands and in its adopted reading, with struck text dropped.

The pages are read by a separate step, `python -m lexflow.municipal.quotes --fetch`; loading the files never goes to the network. The fetch sends GET requests only, with the lexflow-research User-Agent. It obeys robots.txt, waits at least 1.5 s between requests to one host (5 s on the Internet Archive), posts no forms, reads nothing behind a login and uses no browser. www.albemarle.org, www.ci.staunton.va.us and ecode360.com answer HTTP 403, robots.txt included, so their pages are read from the newest Internet Archive capture with HTTP 200, and the capture's timestamp is kept. The text is cached under `<LEXFLOW_DATA>/cache/quote_pages`, so a re-run does not fetch a page again. For albemarle.org and eCode360 the cache keeps only which quotes each page held. The result is stored per file in `place_processes.quote_check`: the file's hash, the counts, how each quote matched, and for each page the day it was read and whether it was live or an archive capture.

**When a file counts as verified.** All of these must hold:

- the AI verifier passed it;
- lexflow's software matched every one of its quotes;
- either the AI check is dated on or after every source's retrieval date (and not in the future), or the software made all its matches on or after those dates.

A quote that did not match is marked where it stands on the page and listed under "Quotes not matched". The page label reads, for example, "121 of 121 quotes matched by lexflow's software: 74 to Open US Law's copy of the Code of Virginia, 47 to the cited pages (42 from Internet Archive copies) on 11 October 2026 · Drafted with an AI system · Not yet reviewed by a person".

**Quote policy** (`quotes.NO_REPRINT`). These sites' terms forbid reposting their content. Their pages are cited and linked, and the quotes stay in the files as evidence. The pages print lexflow's own paraphrase and the link instead, and a "Words not reprinted" note gives the reason and the terms.

**Running it.** The app container has neither pdftotext nor pypdf, so a fetch run there reads no PDF text.
